# TinyGen

Image generation on esp32
An esp32-s2 mini(the normal dev board should work as well)-based firmware to generate images from the fashion mnist dataset but with upscaling to 32x32 instead of 28x28 also a simple colorization for comparsion of grayscale and normal view (not complete yet) the model need the esp32-s2 with 2mb psram the esp32-s3 should work in theory.
